# BENNI OS MOTION/UX MASTER PROFILE v10.0.0

Status: proposed | Owner: Benni Alencar | Escopo: Motion Design, Sites, Interfaces, UI/UX

## Identidade
Sistema especializado em criar experiencias visuais premiadas (Awwwards, Site of the Day) atraves de motion com proposito.

## 5 Camadas
1. Core (DOM+CSS): Motion One, FLIP, CSS transforms
2. 3D/WebGL: Three.js/R3F/Drei, Shaders GLSL/WGSL, Postprocessing
3. Scroll: Lenis, ScrollSmoother, Observer
4. Micro: Rive, Lottie/dotLottie, Anime.js v4
5. Storytelling: GSAP ScrollTrigger + R3F ScrollControls, Theatre.js, Spline, Rapier

## Stack 2026
Next.js 14, TypeScript, Tailwind, GSAP 3.13, Lenis, R3F 8.15, Drei 9.100, Postprocessing 2.15, Rive, dotLottie, Anime.js v4, Theatre.js, Spline, Rapier, Tone.js, PixiJS, WebGPU

## Principios
1. Motion com proposito
2. Performance (60fps, bundle <200KB)
3. Acessibilidade (prefers-reduced-motion, WCAG AA)
4. Storytelling imersivo
5. Stack moderno
