3D DELIVERY GATE v10 - ARTE SUPREMA SEM DEPENDENCIA EXCLUSIVA
================================================================================

Renderer Ladder v10 - com arte em cada tier:

Tier A - HTML/CSS/SVG - Arte com CSS: SDF via box-shadow, noise via SVG filter, breath via CSS animation. Nao e fallback feio, e arte minimalista.

Tier B - Canvas 2D - Fluid 2D com p5.js, 100 particulas, sem WebGL. Arte generativa que roda em Moto G.

Tier C - WebGL2 + Lygia + Theatre.js - SDF, fbm, palette, 3D com luz. Probe de GPU, se falhar vai pra B.

Tier D - WebGPU + GPGPU - 50k particulas, fluid, compute. So se capability + memory ok. Senao C.

Tier E - Poster + HTML + texto equivalente - Foto do resultado 3D + descricao poetica. Nunca tela preta.

Input Ladder - sem dependencia exclusiva:

1. Pointer (mouse/touch) - posicao, velocity, pressure
2. Scroll (Lenis/ScrollSmoother) - progress, velocity, direction
3. Time + Idle - uTime, idleTime, breathTime (respira sozinho se usuario parar)
4. Keyboard - Tab, Enter, Arrow, Space (navegacao ritual)
5. Reduced motion - mantem luz, remove escala
6. (Opcional) Mic/Voice - enhancement, nunca requisito. Se tiver, adiciona uMic como perturbacao sutil, nao controle principal.

Capability Probe v10:
function probeCapability(){
  return {
    webgpu: !!navigator.gpu,
    webgl2: !!document.createElement('canvas').getContext('webgl2'),
    dpr: Math.min(window.devicePixelRatio, 2),
    memory: navigator.deviceMemory || 4,
    cores: navigator.hardwareConcurrency || 4,
    touch: 'ontouchstart' in window,
    reducedMotion: matchMedia('(prefers-reduced-motion: reduce)').matches
  }
}

Se webgpu false, usa webgl2. Se webgl2 false, usa canvas2d. Se canvas2d pesado, usa CSS.

TEMPLATE 1: HALO v2 - RESPIRACAO VIA SCROLL + IDLE, NAO MIC
Nome: HALO - O SITE QUE RESPIRA COM VOCE, SEM PRECISAR DE MIC

Conceito: Site tem ritmo proprio. Quando voce scrolla rapido, ele ofega. Quando para, ele respira fundo. Luz central pulsa com idle time, nao com sopro.

Tech stack sem mic:
- Lenis para scroll velocity
- Theatre.js para breath timeline
- Lygia circleSDF + cnoise para halo organico
- R3F ShaderMaterial com uScrollVelocity + uIdleTime + uTime

Narrativa: Quando usuario para de scrollar, halo respira fundo, texto aparece devagar. Pressa ofega, calma revela. Sem mic, sem permissao, so tempo.

A11y: reduced-motion remove escala, mantem luz. Keyboard: Tab navega, Enter inspira (forca breath). Poster: SVG halo estatico + texto.

================================================================================
TEMPLATE 2: LETHE - MEMORIA QUE APAGA COM SCROLL (JA PERFEITO, SEM MIC)
Nome: LETHE - O SITE QUE ESQUECE QUANTO MAIS VOCE VE

Conceito: Cada secao que voce passa apaga. Fotos viram particulas, textos viram ruido, no fim so branco. Nao volta. Scroll pra cima nao recupera. Unico jeito de rever e ritual de recarregar com intencao.

Tech:
- Lenis + ScrollSmoother para progress que so aumenta (maxProgress)
- GPGPU 50k particulas com vida = 1 - progress
- OGL ou R3F para fluid
- Theatre.js para timeline de apagamento

Narrativa: Sobre desapego. Cada memoria tem 5s para ser lida antes de apagar. Usuario aprende a ler devagar. Final branco com frase: "Algumas coisas so existem se voce nao tentar guardar."

A11y: Versao estatica mostra tudo sem apagar, com aviso: "Esta versao preserva memorias". Keyboard: Space apaga proxima memoria com controle.

================================================================================
TEMPLATE 3: LUMEN v2 - LUZ QUE SEGUE POINTER + FOCUS, NAO VOZ
Nome: LUMEN - O SITE QUE SO ILUMINA ONDE VOCE OLHA

Conceito: Site todo escuro (obsidian). So ilumina onde pointer passa ou onde keyboard focus esta. Texto so aparece na luz. Se voce move rapido, luz grande mas difusa. Se move devagar, luz pequena e nitida. Sussurro virou lentidao, grito virou velocidade.

Tech:
- Pointer tracking com velocity
- Lygia light + SDF
- R3F + shader com uLightPos + uVelocity
- Theatre.js para luz que respira

Narrativa: Sobre atencao. Luz so revela onde voce olha. Resto e mistereo. Usuario aprende a olhar devagar para ver detalhes.

A11y: Versao estatica mostra tudo com luz uniforme. Keyboard: Tab move luz para elemento focado. Poster: SVG com 2 pontos de luz fixos.

TOKEN PROVENANCE v10 - RASTREABILIDADE TOTAL
================================================================================

Todo token tem:
- id: unico (ex: --color-cobalt)
- layer: primitive/semantic/component
- source: design token figma, CSS variable, shader uniform
- depends_on: tokens que ele usa (ex: --surface-canvas depende de --color-obsidian)
- used_by: componentes que usam (ex: .hero usa --surface-canvas)
- a11y_equivalent: token para reduced-motion (ex: --glow-cobalt -> --surface-canvas)
- performance_cost: baixo/medio/alto (ex: --blur-aura: alto em mobile)

Exemplo:
--color-cobalt:
  id: color-cobalt-001
  layer: primitive
  source: figma/design-tokens.json
  depends_on: []
  used_by: [--text-link, --glow-cobalt, .hero-aura]
  a11y_equivalent: --color-cobalt-static (sem animacao)
  performance_cost: baixo

Isso permite:
- Diff de tokens entre versoes
- Impact analysis (mudo --color-cobalt, quebra o que?)
- Auto-fallback (se --blur-aura pesado, usa --surface-canvas)

MEMORY CLEANUP v10 - NUNCA VAZA MEMORIA
================================================================================

Regra: Todo componente que aloca memoria (WebGL, GPGPU, audio) tem:
- allocate(): aloca recursos
- deallocate(): libera recursos
- onContextLoss(): recupera de context loss
- onMemoryPressure(): reduz qualidade se memoria < threshold

Exemplo R3F:
function useGPUParticles(count){
  const [position, setPosition] = useState(null)

  useEffect(()=>{
    // allocate
    const buffer = new Float32Array(count * 3)
    setPosition(buffer)

    return ()=>{
      // deallocate
      buffer.fill(0)
      setPosition(null)
    }
  }, [count])

  useEffect(()=>{
    const handleContextLoss = ()=>{
      // context loss: realoca
      setPosition(new Float32Array(count * 3))
    }
    gl.canvas.addEventListener('webglcontextlost', handleContextLoss)
    return ()=> gl.canvas.removeEventListener('webglcontextlost', handleContextLoss)
  }, [])

  return position
}

Isso evita:
- Vazamento de memoria (componente desmonta, buffer fica)
- Crash em mobile (memoria > 64MB)
- Context loss nao tratado (tela preta)
