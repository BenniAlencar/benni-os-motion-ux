# SKILL 15: PixiJS 2D WebGL Mestre

## O que e
PixiJS = renderizador 2D WebGL (alternativa leve ao Three.js para 2D).

## Instalacao
npm install pixi.js
import { Application, Sprite } from 'pixi.js'

## Padroes
- 2D massivo (particulas, tiles, sprites)
- Mais leve que Three.js para 2D
- WebGL acelerado, fallback Canvas

## QA
- Use para 2D, nao 3D
- Bom para jogos 2D, particulas, tiles
- PixiJS v8+ e moderno, tree-shakeable
