# Workflow Briefing → Producao

## 1. Briefing
- Objetivo do site (vender, informar, converter)
- Publico alvo (idade, dispositivo, regiao)
- Referencias (Awwwards, Dribbble, Behance)
- Restricoes (prazo, budget, tech)

## 2. Wireframe (Figma)
- Estrutura (hero, features, testimonials, CTA, footer)
- Hierarquia visual (titulos, textos, imagens)
- Breakpoints (mobile, tablet, desktop)

## 3. Motion Plan
- Definir camadas (scroll, 3D, micro, shaders)
- Escolher stack (GSAP, R3F, Spline, Rive, Lottie)
- Estimar performance (bundle, fps)

## 4. Desenvolvimento
- Setup (Next.js, Tailwind, deps)
- Implementar por camadas (core → motion → 3D → pos)
- Componentes reutilizaveis

## 5. QA
- Performance (Lighthouse, DevTools)
- Acessibilidade (axe, WAVE)
- Cross-browser (Chrome, Firefox, Safari)
- Mobile (iOS, Android)

## 6. Deploy
- Build, lint, test
- Vercel/Netlify
- Analytics, error tracking

## 7. Pos-lancamento
- Monitoramento (analytics, heatmaps)
- Feedback dos usuarios
- Iteracoes (A/B testing)
