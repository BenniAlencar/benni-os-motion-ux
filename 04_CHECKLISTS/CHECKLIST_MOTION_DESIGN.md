# Checklist Motion Design

## Proposito
- [ ] Cada animacao tem funcao (guiar, informar, emocionar, converter)
- [ ] Nao ha animacao por animar
- [ ] Motion reforca hierarquia visual

## Timing
- [ ] Micro-interacoes: 200-400ms
- [ ] Macro-interacoes: 600-1000ms
- [ ] Transicoes de pagina: 800-1500ms

## Easing
- [ ] Easings naturais (power2.out, power4.out, outBack)
- [ ] Sem linear (exceto scroll scrub)
- [ ] Consistencia em todo o site

## Stagger
- [ ] Distribuido (grid, lista, cards)
- [ ] From center ou from first
- [ ] 50-100ms entre itens

## Scroll
- [ ] Scrub suave (0.5-1s)
- [ ] Pin so quando necessario
- [ ] Markers em dev apenas

## QA
- [ ] Teste em mobile (touch scroll)
- [ ] prefers-reduced-motion
- [ ] 60fps constante
