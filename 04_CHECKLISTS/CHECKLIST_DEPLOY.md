# Checklist Deploy

## Build
- [ ] npm run build sem erros
- [ ] npm run lint sem erros
- [ ] Environment variables configuradas

## Hospedagem
- [ ] Vercel/Netlify/Cloudflare Pages
- [ ] Domain configurado
- [ ] HTTPS ativado
- [ ] Redirect www -> non-www

## Performance
- [ ] Lighthouse >90
- [ ] Bundle <200KB
- [ ] Imagens otimizadas
- [ ] CDN para assets

## Monitoramento
- [ ] Google Analytics / Vercel Analytics
- [ ] Error tracking (Sentry, LogRocket)
- [ ] Uptime monitoring

## SEO
- [ ] Meta tags (title, description, og:image)
- [ ] Sitemap.xml
- [ ] robots.txt
- [ ] Schema.org

## QA Final
- [ ] Teste em 3 browsers (Chrome, Firefox, Safari)
- [ ] Teste em mobile (iOS, Android)
- [ ] Teste em 3G
- [ ] Teste teclado
- [ ] Teste reduced-motion
